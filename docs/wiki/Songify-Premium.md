# Songify Premium

Songify Premium adds **optional** hosted extras and helps fund development. The core app stays **free**; Premium does not remove free functionality.

Any [Ko-fi](https://ko-fi.com/S6S167PLK) membership tier (Orbit, Titan, Cosmos, or Singularity) unlocks the **same** Premium. Higher tiers are extra support, not extra product.

A public comparison lives on [songify.rocks/pricing](https://songify.rocks/pricing).

---

## What Premium includes

- **Premium widgets** on [songify.rocks/widgets](https://songify.rocks/widgets/) (requester spotlights, music scenes, DJ leaderboard, queue alerts, music-night credits, and other gallery styles). Free now-playing and queue widgets stay available.
- **Full top 10** songs and requesters on [songify.rocks/stats](https://songify.rocks/stats). Without Premium you still see totals and ranks 6–10.
- **Stream recap** on [songify.rocks/recap](https://songify.rocks/recap): calendar of request days and the full song list for a day. Busy days are visible without Premium; the list is Premium.
- **Cloud settings sync** in the app: upload, compare, and restore config across PCs.

The desktop app, song requests, Twitch commands, local history, local files, and the local web server stay free.

---

## Activate Premium

1. Become a [Ko-fi](https://ko-fi.com/S6S167PLK) member (any tier).
2. Visit [songify.rocks](https://songify.rocks) and log in with Twitch.
3. Open your account page → **Link Ko-Fi**.
4. Use the **same email** as on Ko-fi.
5. Generate your **Songify token** and add it in the app.

**Settings → Config → Songify Token**, or use **Import to Songify** on the website when offered.

In the app, **Home** and the status-bar **Premium** indicator show whether membership is active. You can refresh status from the token card if you just linked Ko-fi.

## Widgets

Premium widget styles are listed on [songify.rocks/widgets](https://songify.rocks/widgets/). In the app, **Tools → Widget → Widget gallery** or **Browse widgets** on Home opens that page.

Free widgets remain available, including:

- Basic now playing widgets
- Basic queue display
- [Widget Generator](https://widget.songify.rocks)

---

## Token security

- The token is shown **once** when generated.
- If lost, **rotate** and generate a new token on the website.
- The token authenticates Premium features and cloud sync.

---

## Privacy

Ko-fi membership is validated via webhooks. Emails used for matching are handled in line with the privacy policy on the Songify site.
